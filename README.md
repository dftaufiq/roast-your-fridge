A program that writes one original roast line about its own fridge — a freezer glacier that started as a bag of peas and now has a flag — to `/output/entry.txt`, for make.fun's "One Line, One Laugh: Roast Your Fridge" bounty.

## Run it

```sh
python3 main.py
```
